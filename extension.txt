Describe your extension(s) here before implementing them.

- Editor mode dropdown (Regular / Neovim) next to the drawing picker:
    Regular keeps CodeMirror 6; Neovim switches to Ace Editor (https://github.com/ajaxorg/ace)
    with Ace's built-in Vim keymap (hjkl, modes, operators, sticky columns).
- Draggable column splitter between the code editor and the canvas.
- Primary and secondary stroke colour pickers (side by side) in a compact Controls panel.
    Paths alternate by index (even → primary, odd → secondary). Path record unchanged.
- Effects dropdown in Controls + Draw Studio (15 modes): Static, Wave, Cycle, Noise,
    Spiral, plus Pulse, Rainbow, Strobe, Aurora, Chase, Ripple, Scan, Flicker, Twinkle,
    Shimmer — palette animations inspired by livedesign, MetaMapper, Synthlucida, and
    Sparkle. Implemented in color_effects.mjs for the main canvas and Draw Studio.
- Export PNG / GIF buttons (top-right of the canvas): PNG uses the MDN canvas.toBlob
    API; GIF captures the finished drawing looping colour Effects (not the build
    reveal) via gif.js (https://github.com/jnordberg/gif.js).
- Draw Studio (Draw button): a separate overlay window for freehand ink → Gleam
    `Path(Line(...))` code. Ink pipeline: MDN pointer capture + getCoalescedEvents,
    One-Euro live preview (Casiez / stroke-stabilizer), arc-length resample
    ($1 recognizer / Wobbrock UIST 2007), RDP with corner lock (Fleischmann),
    collinear merge, optional auto-close + grid snap. Pressure (or speed-simulated)
    maps to Path thickness. Tools: Pen / Eraser (brush preview + size, segment split),
    Mirror H, Fidelity,
    Effects, colours, Undo/Clear/PNG, Apply to editor. Local unit tests:
    `gleam build && node --test ext_tests/*.test.mjs` (not Gradescope).
